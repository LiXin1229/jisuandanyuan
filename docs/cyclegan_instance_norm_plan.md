# 同帧实例归一化的调度与资源方案

按本次明确的要求，目标改为全部 26 个归一化点使用当前帧、当前通道的全空间统计量。当前已上板版本仍为固定归一化；本文是实施方案和软件可行性验证，尚未改变生产 RTL 或重新上板。

建议采用“卷积输出旁路统计、按通道生成动态 a/b、复用现有 NORM”结构。统计上一 tile 时，让主计算阵列继续执行下一条指令；不需要把完整实例归一化硬塞进 PW 的九拍固定开销。

## 九拍能隐藏什么

当前开启首次舍入的 PW 为 `E=C+9`。从状态机看，可理解为约三拍启动/取数和六拍乘加尾部、量化、写回及完成流程。大部分开销发生在当前结果可用之前；Q4.4 结果接近指令尾部才产生。它不是九拍可任意使用的空闲时间。

共享 PE 的 W 累加器在流水线结束前仍属于当前卷积；CONV 的 `keep_acc/more_acc` 续算期间更不能插入会清累加器的 NORM。当前阵列的权重也是 100 像素共用的，不能直接用一个广播权重同时得到 100 个不同的 x²。

实例归一化包含三个不同步骤：

1. 在卷积已量化为 Q4.4、尚未 ReLU/池化的输出处，累计当前通道的 `S=Σx_raw`、`Q=Σx_raw²` 和有效样本数 N。halo、零填充辅助区域不计入统计。
2. 该通道全部 H×W 数据完成后，计算当前帧的 a/b。可以同时计算其他通道，避免全层全部结束后才开始逐通道算系数。
3. 用当前帧 a/b 执行原来的 `a*x+b`、ReLU、舍入和饱和，再让依赖它的后续层读取。

统计量有全图依赖。第一个 tile 不能在第九拍就获得当前通道尚未生成的后续像素统计量，因此即使局部统计足够快，仍需要保留未归一化特征，并安排回读或片上第二遍处理。

## 数值规则与统计吞吐

沿用参考工程 `tools/live_norm_reference.py` 的整数规则：统计输入为 signed8 Q4.4，使用总体方差，epsilon=1e-5，动态 a/b 为 signed16 Q8.8，系数采用约定的整数开方和 ties-to-even 舍入。它是硬件整数参考，不等同于 float32 逐 bit 结果。

对真实值 `x=x_raw/16`，有：

```text
mu = S / (16*N)
variance = Q / (256*N) - mu*mu
a = gamma / sqrt(variance + epsilon)
b = beta - a*mu
y_raw = sat8((x_raw*a_raw + 16*b_raw + 128) >> 8)
```

实现使用宽整数计算 `D=N*Q-S*S`，避免每个像素执行除法。最大 N=76800 时，S 用 signed25、Q 用 unsigned31 即可；方差乘积需保留约 48 bit，参考的开方输入为 80 bit。只保存当前层、最多 32 通道的统计量和动态系数，不需要同时保存全部层的工作状态。

网络一帧共有 **688 个归一化通道、2841600 个统计样本、28416 个 100 像素 tile**。

| 统计并行度 | 每 tile 采样拍数 | 整帧采样工作量折算 |
| --- | ---: | ---: |
| 1 路 | 100 | 16.576 ms |
| 4 路 | 25 | 4.144 ms |
| 8 路 | 13 | 2.15488 ms |
| 12 路 | 9 | 1.49184 ms |
| 16 路 | 7 | 1.16032 ms |

这些只是采样工作量，不包含平方/归并流水和状态存取，也不是额外增加到帧耗时的实测时间。若严格要求九拍处理 100 个像素，至少需要 12 路采样；加上归并仍不能据此保证九拍完成。

建议比较 4/8 路统计单元的综合结果，优先用 8 路评估吞吐，以“上一 tile 统计与下一条完整指令重叠”为目标。入口保留 ready 背压，统计尚未完成时不能覆盖输入；8 路的 13 拍也不能假设在所有突发、参数 RAM 竞争情况下都无等待。DW3×3 和残差 PW32 的执行时间较长，更容易隐藏这些统计。

开方、除法和系数乘法只配置一套共享迭代单元。以每通道 300 拍作为设计预算，688 通道总工作量约 **1.204 ms**，可与后续通道计算重叠；300 拍不是已经测得的 RTL 延迟，最终需要专项仿真确认。

## 在当前缓存和 DDR 中怎样安排

参考工程的旧 live-norm 控制器按归一化点重跑网络前缀。本工程应复用其整数算法和测试向量，重新安排每层的数据生命周期，避免采用重跑前缀的调度。

| 区域 | 建议安排 | 数据保留约束 |
| --- | --- | --- |
| 编码器 | DW/PW 输出时统计；大特征用 DDR 或片上暂存；PW 后利用正 gamma 提前池化 | 全图统计建立屏障，现有三个编码器逐行穿插调度需调整 |
| 九个残差块 | 先 DW 全通道统计/归一化，再 PW 按输出通道统计/归一化，最后 ADD | 输入 skip 保留至 ADD；三个完整特征张量共 115200 byte，可容纳于现有缓存 |
| 第一个转置卷积 | 输入与完整原始输出优先片上保留，按输出通道统计 | 输入 38400、输出 76800 byte，合计 115200 byte，仍需预留打包 scratch |
| 后两个转置卷积 | 原始输出仍写 DDR；系数就绪后在下一层装载期间归一化，再计算 | 尽量避免把归一化后的整张图再次写回 DDR |
| 7×7 输出层 | 保持 Tanh 路径；读入前一层动态归一化后的数据 | 最终输出层本身没有实例归一化 |

可用 tile 地址为 0..1486，共约 **148700 byte**，不是所有大特征都能驻留。残差的三个 32×30×40 张量占 1152 个 tile，尚有 scratch 余量。DW 临时张量应按 tile 内通道连续的布局供 PW 读取，skip/输出可保持通道优先布局，避免因改变遍历顺序而破坏 PW 连续通道寻址。

残差可按通道遍历全部 12 个 tile；得到该通道统计后启动系数单元，主阵列继续算下一通道。全部 DW 归一化后才开始依赖这些通道的 PW；每个 PW 输出通道也遍历全空间后再归一化和 ADD。通过分配完整特征缓存，避免增加残差 DDR 访存或重新计算卷积。

转置卷积的四个相位属于同一个输出通道、同一张特征图。必须把四相全部有效输出合并统计，不能分别对四相各做一次实例归一化。第二遍 NORM 可从相位计算处移到下一层行装载处；共享 PE 执行 NORM 时，要安排在 CONV 续算组之外。

最大原始特征为 614400 有效 byte，沿用目前每 100 byte tile 占 128 byte 的 DDR 格式需要 786432 byte。暂存使用外部 DDR 地址区，避免增加整帧片上 BRAM。

## 可以精确节省的编码器开销

已核对 checkpoint 的全部 **688 个 gamma 都为正**。因此当前帧系数就绪后，包含整数舍入、饱和及 ReLU 的归一化函数仍单调递增，满足：

```text
MaxPool(Norm(x; full_image_statistics))
  = Norm(MaxPool(x); same_full_image_statistics)
```

这允许先在完整、未池化输出上统计 S/Q，再用已有后处理池化电路暂存原始 2×2 最大值，等 a/b 完成后对较小的池化特征执行 NORM。统计本身必须使用全部未池化像素，不能改用池化后的均值/方差。ReLU 仍放在该层规定的位置；首编码器需要 ReLU，其余 PW 后按原模型配置。

| 编码器 PW 后 | 完整归一化输入 | 原始池化暂存 | 原 NORM 条数 | 调整后条数 |
| --- | ---: | ---: | ---: | ---: |
| 编码器 1 | 614400 byte | 153600 byte | 6144 | 1536 |
| 编码器 2 | 307200 byte | 76800 byte | 3072 | 768 |
| 编码器 3 | 153600 byte | 38400 byte | 1536 | 384 |

三个编码器合计可少 **8064 条 NORM**，按每条 10 拍执行加一拍切换，减少 **88704 拍，约 0.51744 ms 的内核工作量**。整网 NORM 条数由 28416 降到 20352。PW 指令直接复用已有量化/池化后处理并写入池化暂存，无需再增加一条恒等 NORM 来做池化。该方案需要调整目的地址和输出控制，尚未完成 RTL 周期验收；省下的工作量可抵消部分同帧统计开销，不能直接折算为最终 FPS 提升。

## 资源预算与验证顺序

保持 100 路主 PE 和原 NORM 算法。固定 a/b 参数区可以改存 gamma/beta，避免再复制整套模型参数 ROM；动态系数和统计工作区争取使用 1～2 块 BRAM。统计平方运算与共享系数乘法可用少量 DSP，比较 4/8 路方案后按 LUT/FF、时序和背压选型。当前 BRAM 为 249/256，额外资源应由综合确认，本文没有宣称零资源增量。

建议先验证统计与系数模块的极值、零方差、计数、背压及复位，再在片上驻留的残差块实现同帧 IN；随后接入编码器全图屏障和提前池化，最后接入转置输出统计与下一层装载归一化。每次部署均做数值比较、资源/时序检查、上板计数与 git 提交；完整网络最终对同一摄像头帧生成新的同帧 IN 整数参考，并测量持续帧率。
