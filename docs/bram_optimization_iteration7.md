# 放宽至约 200 BRAM 后的 cache 优化

基线 `45fec6e`，固定 epoch11 / 7×7 模型，顶层 `cyclegan_bus_top`，Ti60F225 / C4，Efinity 2026.1.132，100 MHz，关闭 retiming。资源统计包含计算核心、总线、cache、模型参数 ROM 和 Tanh。此次 BRAM 预算由约 180 放宽到约 200。

## 实施结果

| 资源 | 修改前 | 修改后 | 变化 |
|---|---:|---:|---:|
| 整核 LUT4 | 21765 | 20077 | −1688（7.8%） |
| cache 层级 LUT4 | 1813 | 123 | −1690 |
| FF | 5241 | 5239 | −2 |
| BRAM | 147 | 187 | +40 |
| 其中 cache | 120 | 160 | +40 |
| DSP48 | 100 | 100 | 0 |

模型参数仍占 25 BRAM，Tanh 占 2 BRAM。逻辑 cache 容量仍为 1536×800 bit，不增加可访问地址。原有空间窗口寄存器和后处理数据通路不变。

布局布线通过 100 MHz 内部时钟检查，setup slack **1.332 → 1.823 ns**，hold slack **0.026 → 0.028 ns**。这些数据不包含未约束的板级 I/O 路径。

## 用统一地址空间去掉整字选择

原布局为 bank0/1 共用 80 个 `1024×10` TDP，bank2 使用 40 个 `512×20` SDP。bank2 的 host/core 必须共用写入口，因此需要 800 bit 写数据 mux；读端还需要 bank 数据选择及非法地址置零逻辑。

新布局为 **160 个 `2048×5` TDP 位平面**，所有 plane 使用完整的 11 bit 地址：

- 地址 0～1535 对应原有三个 bank；1536～2047 仍为非法地址。
- 端口 A 专用于 host 写，端口 B 用于核心写和共享读取，两个写数据源直接连接各自的原语端口。
- 每个 host 20 bit 写掩码控制四个 5 bit plane；每个核心 200 bit quadrant 控制四十个 plane。
- 各 plane 的读结果直接拼成 800 bit，删除读数据 bank 选择器。

多用的 40 BRAM 来自原语端口宽度与深度布局的改变。第四个 512 深度地址区留空，并不是扩大 ISA 的 feature 地址范围。

## 用 RAM 输出同步复位处理非法读取

仅统一地址空间，仍然保留 `read_ok ? data : 0`，会留下 800 bit 与门。本轮使用 `EFX_DPRAM10` 的 `RESET_RAM_B="SYNC"`：非法读取时，在同一个读取时钟沿同步清零 RAM 的读输出，`rd_valid/host_rvalid` 仍按原有一拍响应。

核对安装模型 `D:/Efinity/2026.1/sim_models/verilog/efx_dpram10.v` 的端口 B 输出过程：同步 reset 在 `CLKEB` 有效时清零 `RDATAB_out`，不会清空存储数组。因此：

- 非法读取返回全零，不保留上一个合法字；非法写入被禁止。
- 非法读后的合法数据和复位后的已存特征仍能读回。
- 空闲时关闭读使能，输出保持；外部 reset 时单独打开 `CLKEB`，保证同步输出复位生效。
- 不使用异步的非法地址复位，避免下一个请求提前改变前一个周期的读结果。

端口 B 使用 `WRITE_MODE_B="NO_CHANGE"`。核心写入时没有读响应；合法读取仍在下一拍返回。host 访问沿用执行器原有的空闲仲裁约束。

## 执行时间及取舍

没有增加 cache 读取级数、装载拍数或计算停顿。PW 输入保持每拍一组，3×3 / 7×7 DW 保持连续 9 / 49 次 MAC；无填充执行时间仍为 30 / 66 拍，排队指令完成后下一拍弹出。

当前 187 BRAM 相对 200 预算还剩 13 个。空间窗口同时给 100 个 PE 提供 800 bit，直接搬入普通 BRAM 必须解决并行读端口、随窗口位置变化的输出排列以及补边读写。这些路由逻辑不会因为把寄存器声明改成 RAM 而消失；本轮保留已验证的寄存器窗口，优先用 40 BRAM 消除两组整字数据选择，不改变计算调度。

## 验证

独立 cache 测试新增 4279 次全字检查：遍历所有合法地址和所有非法地址、三个 bank 的全部 20 bit 写切片及 16 种 quadrant 掩码、非法写入无别名、复位保留内容、空闲保持及连续每拍读取。测试加入 `scripts/run_sim.ps1`。

`scripts/run_cache_mapped.ps1` 独立综合 `mn_cache`，再对综合网表运行同一个 cache 测试。它使用独立临时目录，不覆盖整核综合报告或 staging 指针。结果归档程序同时检查生产网表中全部 160 个 plane 的宽度、同步输出复位和写模式。

独立 cache 网表把两个相同的 800 bit 读输出连接成 800 条逐位 `assign`，Icarus 在反复解析这个宽输出时明显变慢。`sim/coalesce_cache_alias.py` 先严格检查全部 800 个索引均为同位连接，再仅在仿真副本中改为 `assign host_rdata = rd_data;`。两种写法逐位值、默认驱动强度和 X/Z 传播等价，所有功能原语保持原样。原始网表与综合报告不修改，原始/仿真副本 SHA256、变换数量和测试源 SHA256 一并归档。该处理使同样的全地址测试从读取阶段的长时间运行降至约一分钟。

本轮最终通过的检查：

- cache RTL / cache 综合网表各 4279 次全字检查。
- 完整 RTL 回归 201 用例、252 指令，含 9 条预期错误；全部指令的量化、舍入、填充、raw 和 Tanh 执行时间精确匹配周期模型。
- 独立执行跟踪：无填充 3×3 / 7×7 为 30 / 66 拍；四条单通道 PW 各 9 拍，完成到下一条弹出间隔 1 拍。
- 主机总线：PW/DW 黄金结果、背压、复位中断、bank2 逐行掩码、非法地址隔离。
- epoch11 的 RTL / 整核综合网表各 6 条实际参数指令，包括 7×7 CONV/Tanh、第三 bank、扩展参数，均为 860 测试时钟。
- 窗口 216408 像素、后处理 205800 像素、输入 mux 104000 像素、compact 134672 值、模型 ROM/Tanh 及 FIFO RTL/综合网表专项检查。
- 100 MHz 布局布线 setup / hold 均通过。
