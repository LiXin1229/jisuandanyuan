# 八 bank 静态 BRAM 与 100 像素工作窗口

基线 `86ea032`，固定 epoch11 / 7×7 模型顶层 `cyclegan_bus_top`，Ti60F225 / C4，Efinity 2026.1.132，100 MHz，关闭 retiming。预算为约 200 BRAM，统计包含总线、计算核心、全部缓存、参数 ROM 和 Tanh。

E 从 FIFO 弹出沿到 done 沿计算，不包含排队等待。空间核本轮为 `E = 核面积 + 68 + 9×需要修补的边数`；raw 输出减 1，最终 Tanh 增加 54。每条边仍修补三行/列，但从每行/列一拍改为三拍，所以每边从 +3 改为 +9。7×7 DW 为 117～153 拍，7×7 CONV/Tanh 为 171～207 拍。

3×3 / 7×7 的 MAC 仍连续发射 9 / 49 次；增加的是装载和初始化时间。排队指令 done 到下一条弹出仍为 1 拍。该方案适合本轮降低逻辑资源的目标，并不等同于保持原有 DW 总执行时间。

## 256 个原始数据静止，只有 100 个工作数据移动

原来的 16×16 网格在每次 MAC 后整体移位，全部 256 个 cell 都包含装载、补边及三个移动方向的数据选择。

本轮 `mn_dw_buffer_bram.sv` 把 256 个原始字节放入静态 BRAM，只保留 10×10 工作窗口寄存器。工作窗口的移动为固定邻接连线，越界的十个位置从预取边界补入：

- 左移：内部从右邻取值，右侧补十个新字节。
- 右移：内部从左邻取值，左侧补十个新字节。
- 上移：内部从下邻取值，下侧补十个新字节。

BRAM 中原始数据不随 MAC 移动，因此被工作窗口移出的像素仍可在蛇形返回时重新读取。

## 八个 TDP BRAM 同时提供一整行或一整列

采用对角分 bank：`bank = (r+c) mod 8`，bank 内地址为 `{r[3:0], c[3]}`。每个 bank 使用两个 8 bit 端口，实际只用 32 个地址，合计 256 字节。BRAM 数量由并行端口决定。

固定行 r 读取时，bank b 的端口 A 读列 `(b-r) mod 8`，端口 B 读该列加 8；固定列 c 读取时，A 读行 `(b-c) mod 8`，B 读该行加 8。同行/同列的 16 个像素恰好各占一个端口，两个端口地址互不相同。

两组 8 字节结果经共享的循环重排恢复自然顺序，再按当前窗口起点截取连续十个字节。加载和补边也复用整行/整列的地址及数据排列。

## 装载、补边、初始化与预取

9 块邻居 tile 装入对应的 3×3、3×10、10×3 或 10×10 区域，总计 48 次行写入。没有新增 800 bit tile 暂存寄存器：cache 输出在处理当前 tile 时保持。核心把下一 tile 的 cache 读取安排在当前 tile 最后一行写入的同一沿；RAM 写入口采样当前 tile，cache 输出在该沿之后更新，下一沿开始存下一 tile。最后一块有独立完成标记，避免把上一块的完成脉冲当成全部完成。

补边保留原来的反射坐标规则和 X 后 Y 顺序，包括极小特征图及部分 tile。BRAM 先读源行/列，再写目的行/列；控制器推进需额外一拍。零填充走同样的固定时序。

初始化用十次行读取填充工作窗口，直接从核对应的起点开始：7×7 为 (0,0)，3×3 为 (2,2)，小核为 (3,3)，不再执行原来的对齐旋转。

计算时，tap N 的发射同时发出边界读取请求；下一沿 PE 消费 tap N 的窗口，并用已经读出的边界更新窗口。下一次预取的地址会计入同沿正在执行的移动，保证连续 MAC 不因使用旧 x/y 偏移而错一列或一行。RAM 返回的行列基准、截取偏移和初始化标签都打一拍与数据对齐。

旧 `mn_dw_buffer.sv` 保留作历史参考及原专项测试，生产顶层使用新窗口。

## 验证

新增独立窗口测试通过 327100 次像素检查：五种空间核连续蛇形预取、三组数据含零中心 tile、两个补边轴的全部 16 个目的位置及 12 个源位置、零填充、四个视图覆盖全部 256 字节、存储中断复位后重用。

最终检查全部通过：

- 完整 RTL 回归 201 用例、252 指令，8 分片合计 29924 测试周期，含 9 条预期错误；每条指令的正常/舍入/填充/raw/Tanh 拍数精确匹配周期模型。
- 独立六指令跟踪：3×3 / 7×7 为 77 / 117 拍，四条单通道 PW 各 9 拍；全部 9 / 49 次 MAC 顺序正确且连续，排队切换一拍，合计 429 测试周期。
- 总线的 PW/DW 黄金结果、背压、3×3/7×7 中途复位、bank2 行掩码和非法地址隔离。
- 实际 epoch11 的 RTL / 整核综合网表各 6 指令，逐字节一致，均为 1006 测试周期，包含四边反射、7×7 CONV/Tanh、第三 bank 和扩展参数。
- 新窗口 327100 像素检查；后处理 205800 像素、输入 mux 104000 像素、compact 134672 值、ROM/Tanh、FIFO RTL/综合网表及主机协议检查。
- cache RTL 4279 全字检查。本轮 cache 和其测试源未改动，独立 cache 综合网表的 4279 检查复用上一轮结果，并核对源文件和网表哈希。旧寄存器窗口的 216408 检查仅作为历史参考测试，不代替新窗口测试。
- 100 MHz 布局布线 setup / hold 通过。
